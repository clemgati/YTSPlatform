# Vision

## Mission

Build a beautiful, dependable, cross-platform software ecosystem that helps photographers run their studios with fewer mistakes, less repetitive work, and more creative focus.

## Product principles

### Photographer first

Every feature should save time, reduce mistakes, improve creativity, or provide useful insight.

### Offline first

Core studio workflows must remain useful without an internet connection.

### Cross-platform by design

Business logic and reusable user interface code should be shared where doing so improves consistency and maintainability.

### Native where it matters

Platform-specific integrations should use native APIs when a shared abstraction would reduce quality or reliability.

### Zero avoidable data loss

Persistence changes must be versioned, tested, and migrated deliberately.

### One source of truth

Clients, sessions, gear, lighting recipes, deliveries, and portfolio records should not be duplicated across unrelated systems inside the platform.

### Sustainable engineering

Architecture should match the project’s current needs while preserving a clear path to future modularization.

## Product family

### Studio OS

The desktop application for planning, operating, and tracking a photography studio.

### Studio Mobile

A mobile companion for preflight, packing, lighting, shot lists, timers, and client notes.

### Studio Client

A client-facing experience for proofing, selections, releases, and delivery.

### Studio Intelligence

Shared analytics and recommendation capabilities developed from real studio workflows.

## Long-term outcome

Yellow Track Platform should become both:

1. An indispensable internal tool for Yellow Track Studios.
2. A reference-quality Kotlin Multiplatform project that may later support other photographers.
